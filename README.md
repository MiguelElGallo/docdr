# docdr

Documentation doctor for your agent. Based on [Diátaxis](https://diataxis.fr/). We admire the [FastAPI documentation](https://fastapi.tiangolo.com/python-types/).

Packaged as an [Agent Plugin](https://agent-plugins.org/).

## VS Code

Press **⌘⇧P** on macOS or **Ctrl+Shift+P** on Windows/Linux → **Chat: Install Plugin From Source** → enter `https://github.com/MiguelElGallo/docdr` → install → open Copilot Chat → type `/docdr:docdr` and your request.

Prefer exactly `/docdr`? Copy this repository's entire `skills/docdr` folder into your project's `.github/skills/docdr`, then type `/docdr` in Copilot Chat.

## Codex

Copy this repository's entire `skills/docdr` folder into `~/.agents/skills/docdr`. Start a new Codex task, type `$`, select **docdr**, and add your request.
